# Idea-Solution

Company Portfolio Website — a static landing page built from
`idea solution website.svg`. No backend; the compiled CSS is committed, so the
site runs with no build step.

## Run

The site is static — open `index.html`, or serve it:

    npm run serve        # http://localhost:8777

## Build the CSS

`assets/css/styles.css` is generated by the Tailwind CLI and **is committed**,
so the site works with no build step. Rebuild it after editing `index.html`
(new utility classes) or `src/input.css`:

    npm install          # once
    npm run build        # minified, ~23 KB (5.5 KB gzipped)
    npm run watch        # rebuild on change (no cache stamp - use for local dev)

`npm run build` also stamps the `<link>` with a hash of the CSS
(e.g. `styles.css?v=4a24a4bd`). The stylesheet sits at a fixed URL, so without that
a returning visitor can get fresh HTML with a cached older stylesheet and a
broken layout until the cache expires. Always use `npm run build` before
committing, not just `watch`.

Forgetting to rebuild after adding a new utility class is the one way to break
styling — the class simply won't exist in the stylesheet.

## Structure

    index.html           markup
    src/input.css        Tailwind directives + custom CSS
    tailwind.config.js   theme (palette, font, container width)
    assets/css/          generated stylesheet (committed)
    assets/img/          40 images extracted from the source SVG (~1.5 MB)

## Interactions

**Services — pinned heading + stacking cards (768px and up).** The
"Service We Offer" title *and* subtitle sit in a sticky bar pinned under the
site header. Each card is `position: sticky` with a staggered top offset and an
increasing `z-index`, so as you scroll a card pins below that bar and the next
one slides up and covers it, leaving a thin sliver of each card beneath.

The card offset is not hard-coded: a few lines of JS set `--svc-top` from the
measured height of the site header plus the sticky bar, so changing the heading
copy can't knock the cards out of alignment. To change how much of each buried
card shows, edit the `22px` step in
`.svc-card { top: calc(var(--svc-top) + var(--i) * 22px) }`.

Tablets get exactly the same treatment as desktop; only phones (below 768px)
fall back to the stacked card layout.

The pinned bar costs ~255px of viewport and the cards grow taller as the
viewport narrows (608px at 768, 486px at 1000, 456px at 1440), so on screens
too short to show the bar plus a whole card the stacking switches off and the
cards flow as a plain list. The JS measures whether it actually fits and sets
`.svc-no-stack` on the section, rather than relying on a width/height threshold
table that would need a new entry for every breakpoint. Those override
selectors use two classes so they outrank the equal-specificity `md:sticky`
utility regardless of source order.

**Key products — clickable cards.** Each card is an `<a target="_blank"
rel="noopener noreferrer">` that opens the product site in a new tab:
RightEdu → `rightedu.bd`, MediTech → `meditechlis.com`,
Kumari → `konnakumari.com`.

Every affordance (pointer cursor, hover lift, corner arrow) is gated on
`[href]`, so if a URL is ever removed the card goes inert rather than looking
clickable and doing nothing.

**Experts — full-width row, hover to expand.** Pure CSS (`.team-row` /
`.team-card`). Seven cards, CEO in the middle. Every card is a uniform 396px
tall, with the name/designation overlaid on the bottom of the photo rather than
sitting below it — that is what keeps the heights equal.

Sizing is `flex-grow`, not fixed widths, so the row is exactly full width at any
viewport. The lead card is worth 2 units and the other six 1 each; hovering just
swaps which card holds the 2, so the total never changes and the row doesn't
reflow while the cards resize. Only the expanded card shows its caption; the CEO
is expanded by default via `.is-lead`. `:focus-within` mirrors the hover for keyboard users;
gated behind `@media (hover: hover) and (min-width: 640px)`.

On touch devices there is no hover, so the reveal can never fire — there the
cards are widened to 240px and **every** caption is shown, in a horizontally
scrollable row. Without that, five of the six names would be invisible on a
phone.
